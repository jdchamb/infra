# Documentation Subsystem (`docs/`)

This directory contains reference notes, engineering logs, architecture decisions, and project milestones for the USD 308 infrastructure fleet.

---

## Document Index

* **[`308projects.md`](308projects.md):** 
  Log of infrastructure engineering projects, task milestones, and operational resolutions for USD 308 systems (SOPS secrets deployment, CIFS storage automounts, fleet node setup).
* **[`pprojects.md`](pprojects.md):** 
  Personal project backlog, research notes, and architectural roadmap.
* **[`pprojectslearn.md`](pprojectslearn.md):** 
  Engineering learning notes covering NixOS, nix-darwin, systemd boot dependencies, Wayland compositors, and cross-platform dotfile strategies.

---

## Maintenance Note
When completing major fleet changes or solving complex system issues, record the problem, root cause, and resolution in `308projects.md` so that future maintainers have a complete historical trail of all engineering decisions.
